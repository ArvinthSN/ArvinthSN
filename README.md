## Selected engineering work

### SYNOVA — Motor insurance workflow platform
**Applied AI · Backend APIs · Retrieval · Automation**

A prototype insurance aggregation and workflow platform focused on simplifying motor insurance journeys.

- Built backend CRUD workflows and integrated a local PostgreSQL data store.
- Worked on a retrieval-augmented assistant for insurance-domain questions.
- Explored document understanding and workflow automation for renewal and form entry.
- Designed around a React client, FastAPI services, PostgreSQL, and insurer integrations.

**Stack:** React · FastAPI · PostgreSQL · pgvector · LangChain · OCR · LLM APIs

### AI Call Center Analytics
**Speech processing · NLP · Classification**

A pipeline concept for turning multilingual call recordings into structured operational insights.

- Worked on Tamil/Hindi transcription and downstream text classification.
- Focused on extracting call intent and making unstructured conversations easier to analyze.
- Project work has included an evaluation target/result of 87% intent accuracy across 1,000+ calls; measurement depends on the dataset and evaluation split.

**Stack:** Python · Speech-to-text · NLP · Classification · Analytics

### Global LLM Market Analytics
**ETL · Data analysis · Visualization**

An analytics workflow exploring the model ecosystem using public Hugging Face model metadata.

- Collected model metadata for comparative analysis.
- Organized records into an analytics-ready dataset.
- Explored trends and presented findings through dashboards.

**Stack:** Python · Pandas · PostgreSQL · Power BI · Hugging Face
